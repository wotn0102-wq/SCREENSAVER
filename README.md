# 대훈이 시간표 화면보호기

`index.html` 하나로 동작하는 시간표 화면보호기입니다. 인터넷 연결이 필요 없습니다.

- 빨간 **세로 막대선**이 현재 시각을 따라 시간표 위를 이동합니다 (1초마다 갱신).
- 오늘 요일 행은 노란 테두리로 강조, 지난 칸은 흐리게, 지금 칸은 빨간 테두리로 깜빡입니다.
- 상단에 시계와 "지금 할 일 / 남은 시간 / 다음 할 일"이 표시됩니다.
- 9~12시는 모든 요일이 학교라서 원본 표처럼 좁게 압축해 두었습니다 (막대선은 그 구간을 천천히 지나갑니다).
- 주말, 7시 이전, 23시 이후에는 막대선이 숨고 안내 문구가 나옵니다.
- 화면 번인 방지를 위해 5분마다 화면이 살짝 움직입니다.

## 사용법

### 1) 그냥 띄워 두기
`index.html`을 크롬/엣지로 열고 F11을 누르면 전체화면이 됩니다.

### 2) 윈도우 화면보호기로 등록 (듀얼 모니터 지원)
전용 화면보호기 파일(`Timetbl.scr`)을 윈도우에 기본으로 들어 있는 컴파일러로 직접 만듭니다. 별도 프로그램 설치가 필요 없습니다.

1. 이 저장소 전체를 원하는 폴더(예: `C:\시간표`)에 받습니다. (`index.html`, `build.bat`, `saver\Timetbl.cs`)
2. `build.bat` 더블클릭 → 같은 폴더에 `Timetbl.scr` 이 생깁니다.
3. `Timetbl.scr` 마우스 오른쪽 클릭 → **설치** → 대기 시간 지정 후 확인

- 연결된 **모든 모니터**에 시간표가 나옵니다.
- 마우스가 살짝 떨리는 정도(10픽셀 미만)는 무시하고, 크게 움직이거나 키/버튼을 누르면 꺼집니다.
- `index.html` 과 `Timetbl.scr` 은 같은 폴더에 있어야 합니다. 폴더를 옮기면 다시 **설치**하세요.

> 내부적으로 인터넷 익스플로러(IE11) 엔진을 사용합니다.
> 그래서 `index.html`은 IE11에서도 동작하는 문법(ES5 자바스크립트, CSS 변수·grid 미사용)으로 작성되어 있습니다.
> 시간표를 고칠 때도 `const`, `=>` 같은 최신 문법은 쓰지 마세요. "스크립트 오류" 창이 뜹니다.

## 시간표 수정
`index.html` 안의 `SCHEDULE` 부분에서 `["시작", "끝", "이름", "색상"]` 형식으로 고치면 됩니다. 이름 안의 `|`는 줄바꿈입니다.
색상 종류: `study`(보라) `meal`(분홍) `school`(하늘) `hw`(노랑) `free`(민트) `tkd`(주황) `night`(회색)

## 미리보기
주소 뒤에 `?t=2026-09-29T18:40` 처럼 붙이면 그 시각 기준으로 화면을 확인할 수 있습니다.
